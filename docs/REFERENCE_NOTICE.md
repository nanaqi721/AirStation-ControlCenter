# 参考资料使用声明

## 资料定位

本项目以用户提供的“新阁教育”Modbus RTU 项目课件资料、设计图、点表、配置和工具类作为学习与需求分析参考。本资料包中的项目规划不是原课程项目的复制品，而是基于已经确定的技术栈，面向空压机集控场景进行的独立 0 到 1 设计。

“新阁教育”、课程名称、课件内容、图片、视频、示例程序、商标及其他可能受保护的内容，其权利归原权利人所有。将本资料用于学习之外的用途前，应自行确认授权和适用许可。

## 使用边界

- 可以参考业务需求、功能范围、点表结构、信息布局和教学思路。
- 项目代码应独立编写，不逐行照搬课程示例或未知许可的源码。
- 正式产品不要直接复用带有课程品牌、水印或第三方版权的图片和界面素材；应替换为自有或已获许可的资源。
- 不要在未确认许可和兼容性的情况下，把资料中的 DLL、控件或可执行程序直接带入生产版本。
- 示例账号、明文密码、默认口令和示例连接参数不得用于真实环境。
- 所有 NuGet 包、字体、图标、报表库和导出库在发布前都需要检查许可证。

## 关于视频

教学视频本身没有打包进来。功能分析只读取了 P26—P97 的文件名/标题，没有打开或播放视频。标题只能说明课程大致覆盖范围，不能证明视频内的具体实现质量、源代码结构或工程适用性。

## 关于参考代码和工具

初步检查显示，课件资料更接近“点表 + 设计图片 + 配置 + 模拟器 + 若干工具类/示例组件”，不是一个可以直接构建、部署和维护的完整主项目源码。因此，本项目将资料视为需求线索，不把其中的结构、通信实现或数据库实现默认认定为最佳实践。

本项目已经决定使用 NModbus 完成 Modbus RTU 协议收发，不自行复制课程中的协议帧实现。NModbus 以及其他第三方依赖仍需在实际使用的版本中保留并遵守其许可声明。

## 工业安全声明

本项目是监控和管理上位机，不是经过安全认证的保护系统。急停、超压、超温、缺水、电机保护等关键联锁必须在 PLC、保护继电器或设备本地控制器内独立实现；网络、上位机或数据库故障不能导致这些保护失效。

课件中的串口号、波特率、从站地址、点位地址、量程和控制值都只是参考。连接真实设备或发出控制命令前，必须依据设备手册、现场点表和联调记录逐项确认。
