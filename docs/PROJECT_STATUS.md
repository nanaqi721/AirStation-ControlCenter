## 已确定决策

| 项目 | 决策 |
|---|---|
| 应用类型 | Windows Forms 桌面上位机 |
| 目标框架 | .NET 7，项目目标框架为 `net7.0-windows` |
| Modbus | 使用 NModbus，不自行编写 RTU 协议栈 |
| 串口支持 | NModbus.Serial 与 System.IO.Ports |
| 数据库 | SQLite，优先使用 Microsoft.Data.Sqlite |
| 配置 | JSON 配置文件；运行时参数由统一配置服务读取与校验 |
| 第一阶段通信拓扑 | 一个从站（Slave ID 1）代表整个空压站 PLC |
| 项目性质 | 面向第一次开发上位机的 0 到 1 教学型实战项目，同时按真实工程思路设计 |
| 资料使用 | 教学资料仅作需求、点表、界面和思路参考，独立设计与实现 |
| 安全边界 | 急停、超压、超温、缺水等关键联锁由 PLC/本地控制器负责；上位机不是唯一安全层 |
| 写入规则 | 默认不创建或修改项目文件；只有用户明确授权写入时才落盘 |
| 文档布局 | 完整协作规则放在根目录 `AGENTS.md`，其他项目文档放在 `docs/`，根目录 `README.md` 提供导航；文档相对链接以所在目录为基准 |
